# RAG Evaluation Platform

A self-hosted platform for benchmarking Retrieval-Augmented Generation
(RAG) systems: retrieval quality (Precision@K, Recall@K, MRR, MAP,
NDCG, HitRate), generation quality (Faithfulness, Correctness,
Semantic Similarity), and an LLM-as-judge layer (faithfulness,
answer relevance, hallucination) — with a FastAPI backend, a
persisted leaderboard, JSON/CSV/Markdown reports, and a live
dashboard.

## Quickstart (single command, zero config)

```bash
cd backend
pip install -r requirements.txt
python scripts/run_evaluation.py
```

That's it. This will:

1. Load the bundled benchmark dataset (`app/datasets/sample_dataset.json`)
2. Run every registered evaluator (retrieval, generation, LLM judge)
3. Persist `Evaluation` + `Metric` rows and mark the benchmark `completed`
4. Refresh the leaderboard (computed live from the DB — no extra step)
5. Generate `reports/report.{json,csv,md}` (and per-benchmark copies)
6. Print a summary to the terminal

By default it uses a local SQLite database (`backend/rag_eval.db`)
and a deterministic, **offline** mock LLM judge — no API key, no
Docker, no external services required to see the whole pipeline run.

To point it at a real Gemini judge and real embeddings instead, see
[Switching to real LLM/embeddings](#switching-to-real-llmembeddings-optional).

## Run it again, compare runs

```bash
python scripts/run_evaluation.py --experiment "gpt-4o-mini"
python scripts/run_evaluation.py --experiment "gemini-2.5-flash"
```

Every run creates a new `Benchmark` row, so the leaderboard and the
dashboard's "Run Comparison" chart accumulate history across runs —
useful for comparing RAG configurations, prompts, or models. See
`python scripts/run_evaluation.py --help` for all options
(`--dataset`, `--project`, `--experiment`, `--benchmark`,
`--reports-dir`).

## See it in the browser

```bash
# Terminal 1 — API
cd backend
uvicorn app.main:app --reload --port 8000
# -> http://localhost:8000/docs

# Terminal 2 — Dashboard (static files, no build step)
cd frontend
python3 -m http.server 5500
# -> http://localhost:5500
```

The dashboard's API base URL is editable in its top bar (defaults to
`http://127.0.0.1:8000`) and auto-refreshes every 8 seconds. It shows:

- Overview stats (projects, datasets, experiments, benchmarks, evaluations, average score)
- A ranked leaderboard across every benchmark run
- A run-comparison bar chart and a retrieval / generation / LLM-judge metric breakdown
- A benchmark drill-down: per-metric radar chart, per-sample table, and JSON/CSV/Markdown report downloads
- A "Pipeline Run" panel that mirrors the latest `run_evaluation.py` output

## Project layout

```

  app/
    api/routes/         FastAPI routers (projects, datasets, experiments,
                         benchmarks, reports, leaderboard, summary)
```

## Running the tests

```bash
cd backend
pip install -r requirements.txt
pytest
```

The suite (53 tests) covers:

- **Metrics** (`tests/test_metrics.py`) — each retrieval/generation metric in isolation
- **Dataset loading & validation** (`tests/test_dataset_loader.py`)
- **Evaluation engine** (`tests/test_engine.py`) — every evaluator runs and returns typed scores
- **Benchmark runner** (`tests/test_benchmark.py`) — full dataset run, aggregate scores
- **Report generators** (`tests/test_reports.py`) — JSON/CSV/Markdown content assertions
- **API** (`tests/test_api.py`) — FastAPI endpoints via `TestClient`, against an isolated SQLite DB
- **Pipeline integration** (`tests/test_run_evaluation.py`) — invokes `run_evaluation.py`'s
  `main()` directly and asserts on the DB rows and report files it produces

Tests run entirely offline against a temporary SQLite database
(`LLM_PROVIDER=mock` by default in `tests/conftest.py`), so no API
key or network access is required in CI.

## Switching to real LLM/embeddings (optional)

By default the platform runs fully offline:

- `LLM_PROVIDER=mock` — a deterministic, lexical-overlap heuristic stands
  in for the LLM judge (`app/llm/mock.py`)
- `SemanticSimilarity` falls back to token-overlap similarity if
  `sentence-transformers` / an embeddings model isn't available

For production-quality scoring:

```bash
cp backend/.env.example backend/.env
# edit backend/.env:
#   LLM_PROVIDER=gemini
#   GEMINI_API_KEY=your-key-here
pip install google-genai sentence-transformers torch
python scripts/run_evaluation.py
```

## Run everything with Docker (one command)

```bash
docker compose up --build
```

This starts three containers and wires them together automatically:

| Service    | What it does                                                              | URL                            |
|------------|----------------------------------------------------------------------------|---------------------------------|
| `db`       | Postgres 16                                                                | `localhost:5432`               |
| `backend`  | Runs Alembic migrations, seeds a demo benchmark, then starts the API       | `http://localhost:8000/docs`   |
| `frontend` | Nginx serving the static dashboard                                        | `http://localhost:5500`        |

On first boot the backend container automatically runs
`scripts/run_evaluation.py` once (`SEED_ON_START=true` by default) so
the dashboard has data as soon as everything is up — open
`http://localhost:5500` after a few seconds. Reports are written to
`./backend/reports` on the host (mounted as a volume) so they persist
across restarts and are easy to inspect.

By default the seeded run uses the offline mock LLM judge (no API key
needed). To seed with a real Gemini judge instead:

```bash
export LLM_PROVIDER=gemini
export GEMINI_API_KEY=your-key-here
docker compose up --build
```

Other useful commands:

```bash
# Run the pipeline again inside the running backend container
docker compose exec backend python scripts/run_evaluation.py --experiment "gpt-4o-mini"

# Tear everything down (add -v to also wipe the Postgres volume)
docker compose down
```

If your Docker install uses the older standalone `docker-compose`
binary, substitute `docker-compose` for `docker compose` above.

def run_migrations_offline() -> None:
    """Run migrations in 'offline' mode.

    This configures the context with just a URL
    and not an Engine, though an Engine is acceptable
    here as well.  By skipping the Engine creation
    we don't even need a DBAPI to be available.

    Calls to context.execute() here emit the given string to the
    script output.

    """
    url = config.get_main_option("sqlalchemy.url")
    context.configure(
        url=url,
        target_metadata=target_metadata,
        literal_binds=True,
        dialect_opts={"paramstyle": "named"},
    )

    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    """Run migrations in 'online' mode.

    In this scenario we need to create an Engine
    and associate a connection with the context.

    """
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}),
        prefix="sqlalchemy.",
        poolclass=pool.NullPool,
    )

    with connectable.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)

        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()

from app.experiments.experiment import (
    ExperimentManager,
)


class ExperimentRegistry:
    """
    In-memory registry for active experiments.
    """

    _experiments: dict[
        str,
        ExperimentManager,
    ] = {}

    @classmethod
    def register(
        cls,
        manager: ExperimentManager,
    ) -> None:
        """
        Register an experiment manager.
        """

        cls._experiments[manager.experiment.experiment_id] = manager

    @classmethod
    def get(
        cls,
        experiment_id: str,
    ) -> ExperimentManager | None:
        """
        Retrieve an experiment by its ID.
        """

        return cls._experiments.get(experiment_id)

    @classmethod
    def list(
        cls,
    ) -> list[ExperimentManager]:
        """
        Return all registered experiments.
        """

        return list(cls._experiments.values())

    @classmethod
    def unregister(

@dataclass(slots=True)
class BenchmarkResult:
    """
    Represents the outcome of a benchmark execution.
    """

    # Unique benchmark identifier
    benchmark_id: str = field(default_factory=lambda: str(uuid4()))

    # Dataset information
    dataset_name: str = ""
    dataset_version: str = "1.0"

    # Execution statistics
    total_samples: int = 0
    successful_samples: int = 0
    failed_samples: int = 0

    # Timing
    started_at: datetime = field(default_factory=datetime.utcnow)
    completed_at: datetime | None = None
    duration_ms: float = 0.0

    # Aggregated metrics
    average_scores: dict[str, float] = field(default_factory=dict)

    # Per-sample evaluation results
    results: list[EvaluationSummary] = field(default_factory=list)

    # Failed evaluations
    errors: list[BenchmarkError] = field(default_factory=list)

    # Runtime information
    metadata: dict[str, Any] = field(default_factory=dict)

    @property
    def success_rate(self) -> float:
        """
        Percentage of successfully evaluated samples.
        """

        if self.total_samples == 0:
            return 0.0

        return round(
            self.successful_samples / self.total_samples,
            4,
        )

    @property
    def failure_rate(self) -> float:
        """
        Percentage of failed samples.
        """

        if self.total_samples == 0:
            return 0.0

        return round(
            self.failed_samples / self.total_samples,
            4,
        )

    @property
    def is_successful(self) -> bool:
        """
        True if all samples were evaluated successfully.
        """

        return self.failed_samples == 0

    def add_result(
        self,
        result: EvaluationSummary,
    ) -> None:
        """
        Add a single sample evaluation.
        """

        self.results.append(result)

    def add_error(
        self,
        *,
        sample: int,
        question: str,
        error: str,
    ) -> None:
        """
        Add a failed sample.
        """

        self.errors.append(
            BenchmarkError(
                sample=sample,
                question=question,
                error=error,
            )
        )

from collections import defaultdict
from datetime import datetime
import time

from app.core.config import settings

from app.datasets.validator import DatasetValidator
from app.evaluation.engine import EvaluationEngine
from app.evaluation.models import EvaluationRequest
from app.experiments.models import BenchmarkResult


class BenchmarkRunner:
    """
    Executes an entire benchmark dataset using the EvaluationEngine.
    """

    def __init__(self) -> None:
        self.engine = EvaluationEngine()

    def run(
        self,
        dataset: Dataset,
    ) -> BenchmarkResult:

        DatasetValidator.validate(dataset)

        started_at = datetime.utcnow()
        start_timer = time.perf_counter()

        metric_totals: dict[str, float] = defaultdict(float)
        metric_counts: dict[str, int] = defaultdict(int)

        successful = 0
        failed = 0

        benchmark = BenchmarkResult(
            dataset_name=dataset.name,
            total_samples=len(dataset),
            started_at=started_at,
            metadata={
                "provider": settings.LLM_PROVIDER,
                "model": settings.GEMINI_MODEL,
                "engine": "EvaluationEngine",
            },
        )

        batch_size = settings.LLM_BATCH_SIZE

        for batch_start in range(
            0,
            len(dataset.samples),
            batch_size,
        ):

            batch_samples = dataset.samples[batch_start : batch_start + batch_size]

            # print(
            #     f"Processing batch {batch_start // batch_size + 1} "
            #     f"({len(batch_samples)} samples)"
            # )

            batch_requests = []

            for sample in batch_samples:

                batch_requests.append(
                    EvaluationRequest(
                        query=sample.question,
                        contexts=sample.contexts,
                        answer=sample.answer,
                        ground_truth=sample.ground_truth,
                        relevant_contexts=sample.relevant_contexts,
                    )
                )

            try:

                summaries = self.engine.evaluate_batch(batch_requests)

                for sample, summary in zip(
                    batch_samples,
                    summaries,
                ):

                    benchmark.add_result(summary)

                    successful += 1

                    for evaluator in summary.evaluators:

                        for metric in evaluator.metrics:

                            metric_totals[metric.name] += metric.score
                            metric_counts[metric.name] += 1

            except Exception as exc:

                failed += len(batch_samples)

                for offset, sample in enumerate(batch_samples):

                    benchmark.add_error(
                        sample=batch_start + offset + 1,
                        question=sample.question,
                        error=str(exc),
                    )

        average_scores = {
            metric_name: round(
                metric_totals[metric_name] / metric_counts[metric_name],
                4,
            )
            for metric_name in metric_totals
        }

        benchmark.successful_samples = successful
        benchmark.failed_samples = failed
        benchmark.completed_at = datetime.utcnow()

        benchmark.duration_ms = round(
            (time.perf_counter() - start_timer) * 1000,
            2,
        )

        benchmark.average_scores = average_scores

        return benchmark

class LLMJudgeEvaluator(BaseEvaluator):
    """
    Evaluates RAG responses using an LLM as a judge.
    """

    def __init__(self) -> None:
        self.client = LLMClient()

    def evaluate(
        self,
        request: EvaluationRequest,
    ) -> EvaluatorResult:
        """
        Evaluate a generated answer using an LLM.
        """

        prompt = f"""
You are an expert RAG evaluation assistant.

Evaluate the generated answer using ONLY the retrieved context.

Instructions:

- Score each metric between 0.0 and 1.0.
- Do NOT use outside knowledge.
- If the answer contains unsupported facts, increase hallucination.
- Return ONLY valid JSON.
- Do NOT wrap the JSON in markdown.
- Do NOT include explanations outside the JSON.

Question:
{request.query}

Retrieved Context:
{chr(10).join(request.contexts)}

Generated Answer:
{request.answer}

Return exactly this JSON schema:

{{
    "faithfulness": 0.0,
    "answer_relevance": 0.0,
    "hallucination": 0.0,
    "reason": ""
}}
"""
        
        try:
            response = self.client.evaluate(prompt)

        except Exception as exc:
            return EvaluatorResult(
                evaluator="LLMJudgeEvaluator",
                metrics=[
                    MetricResult(
                        name="llm_faithfulness",
                        score=0.0,
                    ),
                    MetricResult(
                        name="answer_relevance",
                        score=0.0,
                    ),
                    MetricResult(
                        name="hallucination",
                        score=1.0,
                    ),
                ],
                metadata={
                    "provider": settings.LLM_PROVIDER,
                    "model": settings.GEMINI_MODEL,
                    "error": str(exc),
                },
            )

        try:
            result = LLMResponseParser.parse(response)

        except ValueError as exc:

            metadata = {
                "provider": settings.LLM_PROVIDER,
                "model": settings.GEMINI_MODEL,
                "error": str(exc),
            }

            if settings.DEBUG:
                metadata["prompt"] = prompt
                metadata["raw_response"] = response

            return EvaluatorResult(
                evaluator="LLMJudgeEvaluator",
                metrics=[
                    MetricResult(
                        name="llm_faithfulness",
                        score=0.0,
                    ),
                    MetricResult(
                        name="answer_relevance",
                        score=0.0,
                    ),
                    MetricResult(
                        name="hallucination",
                        score=1.0,
                    ),
                ],
                metadata=metadata,
            )

        metadata = {
            "reason": result["reason"],
            "provider": settings.LLM_PROVIDER,
            "model": settings.GEMINI_MODEL,
        }

        if settings.DEBUG:
            metadata["prompt"] = prompt
            metadata["raw_response"] = response

        return EvaluatorResult(

                ),
            ],
            metadata=metadata,
        )

    def _build_batch_prompt(
        self,
        requests: list[EvaluationRequest],
    ) -> str:

        items = []

        for index, request in enumerate(requests, start=1):
            items.append(
                f"""
    Item {index}

    Question:
    {request.query}

    Retrieved Context:
    {chr(10).join(request.contexts)}

    Generated Answer:
    {request.answer}
    """
            )

        return f"""
    You are an expert RAG evaluation assistant.

    Evaluate every item independently.

    Rules:

    - Use ONLY the retrieved context.
    - Score between 0.0 and 1.0.
    - Return ONLY valid JSON.
    - Do NOT use markdown.
    - Return a JSON array.

    Return exactly {len(requests)} JSON objects.

    The first object corresponds to Item 1.
    The second object corresponds to Item 2.
    Continue in the same order.
    Do not omit, reorder, or merge items.

    Example:

    [
    {{
        "faithfulness": 0.0,
        "answer_relevance": 0.0,
        "hallucination": 0.0,
        "reason": ""
    }}
    ]

    Items:

    {chr(10).join(items)}
    """

        self,
        requests: list[EvaluationRequest],
    ) -> list[EvaluatorResult]:

        Evaluate multiple requests in a single LLM call.

        if not requests:

                            "error": str(exc),
                        },
                    )
                )

            return results

        try:
            parsed_results = LLMResponseParser.parse_batch(response)

        except ValueError as exc:

            results = []

            for _ in requests:

                metadata = {
                    "provider": settings.LLM_PROVIDER,
                    "model": settings.GEMINI_MODEL,
                    "error": str(exc),
                }

                if settings.DEBUG:
                    metadata["prompt"] = prompt
                    metadata["raw_response"] = response

                results.append(
                    EvaluatorResult(
                        evaluator="LLMJudgeEvaluator",
                        metrics=[
                            MetricResult(
                                name="llm_faithfulness",
                                score=0.0,
                            ),
                            MetricResult(
                                name="answer_relevance",
                                score=0.0,
                            ),
                            MetricResult(
                                name="hallucination",
                                score=1.0,
                            ),
                        ],
                        metadata=metadata,
                    )
                )

            return results

        if len(parsed_results) != len(requests):

            results = []

            for _ in requests:

                results.append(
                    EvaluatorResult(
                        evaluator="LLMJudgeEvaluator",
                        metrics=[
                            MetricResult(
                                name="llm_faithfulness",
                                score=0.0,
                            ),

                                name="answer_relevance",
                                score=0.0,

                    )
                )

            return results

        results = []

        for result in parsed_results:

class EvaluatorRegistry:
    """
    Registry for all available evaluators.
    """

    _evaluators: list[type[BaseEvaluator]] = [
        RetrievalEvaluator,
        GenerationEvaluator,
        LLMJudgeEvaluator,
    ]

    @classmethod
    def get_evaluators(
        cls,
    ) -> list[BaseEvaluator]:
        """
        Return instances of all registered evaluators.
        """

        return [evaluator() for evaluator in cls._evaluators]

    @classmethod
    def register(
        cls,
        evaluator: type[BaseEvaluator],
    ) -> None:
        """
        Register a new evaluator.
        """

        if evaluator not in cls._evaluators:
            cls._evaluators.append(evaluator)

    @classmethod
    def unregister(
        cls,
        evaluator: type[BaseEvaluator],
    ) -> None:
        """
        Remove an evaluator from the registry.
        """

        if evaluator in cls._evaluators:
            cls._evaluators.remove(evaluator)

    @classmethod
    def clear(cls) -> None:
        """
        Remove all registered evaluators.
        """

        cls._evaluators.clear()

Rules:

from app.evaluation.models import (
    EvaluationRequest,
    EvaluationSummary,
)
from app.evaluation.registry import EvaluatorRegistry


class EvaluationEngine:
    """
    Executes all registered evaluators.
    """

    def __init__(self) -> None:
        self.evaluators = EvaluatorRegistry.get_evaluators()

    def evaluate(
        self,
        request: EvaluationRequest,
    ) -> EvaluationSummary:
        """
        Run all evaluators for a single request.
        """

        summary = EvaluationSummary()

        for evaluator in self.evaluators:
            result = evaluator.evaluate(request)
            summary.evaluators.append(result)

        return summary

    def evaluate_batch(
        self,
        requests: list[EvaluationRequest],
    ) -> list[EvaluationSummary]:
        """
        Run all evaluators for multiple requests.
        """

        summaries = [EvaluationSummary() for _ in requests]

        for evaluator in self.evaluators:

            results = evaluator.evaluate_batch(requests)

            if len(results) != len(requests):
                raise ValueError(
                    f"{evaluator.__class__.__name__} returned "
                    f"{len(results)} results for "
                    f"{len(requests)} requests."
                )

            for summary, result in zip(
                summaries,
                results,
            ):
                summary.evaluators.append(result)

        return summaries

        with output_path.open(
            "w",
            newline="",
            encoding="utf-8",
        ) as csvfile:

            writer = csv.DictWriter(
                csvfile,
                fieldnames=fieldnames,
            )

            writer.writeheader()
            writer.writerows(rows)

from app.datasets.exceptions import DatasetValidationError
from app.datasets.models import Dataset


class DatasetValidator:
    """
    Validates Dataset objects before they are used
    for benchmarking or evaluation.
    """

    @staticmethod
    def validate(dataset: Dataset) -> None:
        """
        Validate an entire dataset.

        Raises:
            DatasetValidationError:
                If any validation rule fails.
        """

        if dataset is None:
            raise DatasetValidationError("Dataset cannot be None.")

        if not dataset.name.strip():
            raise DatasetValidationError("Dataset name cannot be empty.")

        if not dataset.samples:
            raise DatasetValidationError("Dataset contains no samples.")

        seen_questions: set[str] = set()

        for index, sample in enumerate(
            dataset.samples,
            start=1,
        ):

            # -----------------------------
            # Question
            # -----------------------------
            if not isinstance(sample.question, str):
                raise DatasetValidationError(
                    f"Sample #{index}: question must be a string."
                )

            if not sample.question.strip():
                raise DatasetValidationError(
                    f"Sample #{index}: question cannot be empty."
                )

            # -----------------------------
            # Duplicate Questions
            # -----------------------------
            normalized_question = sample.question.strip().lower()

            if normalized_question in seen_questions:
                raise DatasetValidationError(
                    f"Sample #{index}: duplicate question " f"'{sample.question}'."
                )

            seen_questions.add(normalized_question)

            # -----------------------------
            # Contexts
            # -----------------------------
            if not isinstance(sample.contexts, list):
                raise DatasetValidationError(
                    f"Sample #{index}: contexts must be a list."
                )

            if len(sample.contexts) == 0:
                raise DatasetValidationError(
                    f"Sample #{index}: contexts cannot be empty."
                )

            for context_index, context in enumerate(
                sample.contexts,
                start=1,
            ):

                if not isinstance(context, str):
                    raise DatasetValidationError(
                        f"Sample #{index}: "
                        f"context #{context_index} "
                        f"must be a string."
                    )

                if not context.strip():
                    raise DatasetValidationError(
                        f"Sample #{index}: "
                        f"context #{context_index} "
                        f"cannot be empty."
                    )

            # -----------------------------
            # Answer
            # -----------------------------
            if not isinstance(sample.answer, str):
                raise DatasetValidationError(
                    f"Sample #{index}: answer must be a string."
                )

            if not sample.answer.strip():
                raise DatasetValidationError(
                    f"Sample #{index}: answer cannot be empty."
                )

            # -----------------------------
            # Ground Truth
            # -----------------------------
            if sample.ground_truth is not None and not isinstance(
                sample.ground_truth,
                str,
            ):
                raise DatasetValidationError(
                    f"Sample #{index}: " "ground_truth must be a string " "or None."
                )

            if isinstance(sample.ground_truth, str) and not sample.ground_truth.strip():
                raise DatasetValidationError(
                    f"Sample #{index}: " "ground_truth cannot be empty."
                )

            # -----------------------------
            # Metadata
            # -----------------------------
            if not isinstance(sample.metadata, dict):
                raise DatasetValidationError(
                    f"Sample #{index}: " "metadata must be a dictionary."
                )

from math import log2

from app.evaluation.models import EvaluationRequest
from app.metrics.base import BaseMetric


class NDCG(BaseMetric):

    def compute(
        self,
        request: EvaluationRequest,
    ) -> float:

        k = self.config.get("k", len(request.contexts))

        retrieved = request.contexts[:k]
        relevant = request.relevant_contexts

        if not retrieved or not relevant:
            return 0.0

        # DCG Calculate for nDCG
        dcg = 0.0

        for rank, document in enumerate(retrieved, start=1):
            if document in relevant:
                dcg += 1 / log2(rank + 1)

        ideal_hits = min(len(relevant), k)
        # Ideal DCG for nDCG
        idcg = sum(1 / log2(rank + 1) for rank in range(1, ideal_hits + 1))

        if idcg == 0:
            return 0.0

        return dcg / idcg

    "part",
    "official",
}


def _content_tokens(text: str) -> set[str]:
    tokens = set(re.findall(r"[a-z0-9]+", text.lower()))
    return {token for token in tokens if token not in _STOPWORDS}


class Faithfulness(BaseMetric):
    """
    Graded faithfulness score: the fraction of the answer's content
    words that are grounded in the retrieved context. 1.0 means every
    claim word in the answer is backed by the context; lower scores
    indicate potentially unsupported (hallucinated) content.
    """

    def compute(
        self,
        request: EvaluationRequest,
    ) -> float:

        answer_tokens = _content_tokens(request.answer)

        if not answer_tokens:
            return 0.0

        context_tokens = _content_tokens(" ".join(request.contexts))

        if not context_tokens:
            return 0.0

        supported = len(answer_tokens & context_tokens)

        return round(supported / len(answer_tokens), 4)

import re

from app.evaluation.models import EvaluationRequest
from app.metrics.base import BaseMetric


def _tokenize(text: str) -> set[str]:
    return set(re.findall(r"[a-z0-9]+", text.lower()))


class SemanticSimilarity(BaseMetric):
    """
    Cosine similarity between the answer and ground truth embeddings.

    Loads a sentence-transformers model lazily on first use. If the
    model can't be loaded (no internet access, dependency not
    installed, etc.) this degrades gracefully to a Jaccard
    token-overlap similarity, so the evaluation pipeline still runs
    end to end in offline / demo environments.
    """

    _model = None
    _model_load_failed = False

    def __init__(self, **config):
        super().__init__(**config)
        self.model_name = config.get("model_name", "all-MiniLM-L6-v2")

    def compute(
        self,
        request: EvaluationRequest,
    ) -> float:

        if not request.ground_truth:
            return 0.0

        model = self._get_model(self.model_name)

        if model is not None:
            try:
                from sentence_transformers.util import cos_sim

                answer_embedding = model.encode(
                    request.answer,
                    convert_to_tensor=True,
                )

                truth_embedding = model.encode(
                    request.ground_truth,
                    convert_to_tensor=True,
                )

                similarity = cos_sim(
                    answer_embedding,
                    truth_embedding,
                )

                return round(float(similarity.item()), 4)

            except Exception:
                # Fall through to the lexical fallback below.
                pass

        return self._lexical_similarity(
            request.answer,
            request.ground_truth,
        )

    @classmethod
    def _get_model(cls, model_name: str):
        if cls._model is not None:
            return cls._model

        if cls._model_load_failed:
            return None

        try:
            from sentence_transformers import SentenceTransformer

            cls._model = SentenceTransformer(model_name)

            return cls._model

        except Exception:
            cls._model_load_failed = True
            return None

    @staticmethod
    def _lexical_similarity(answer: str, ground_truth: str) -> float:
        answer_tokens = _tokenize(answer)
        truth_tokens = _tokenize(ground_truth)

        if not answer_tokens or not truth_tokens:
            return 0.0

        intersection = len(answer_tokens & truth_tokens)
        union = len(answer_tokens | truth_tokens)

        return round(intersection / union, 4) if union else 0.0

class MAP(BaseMetric):

        self,
        request: EvaluationRequest,
    ) -> float:

        k = self.config.get("k", len(request.contexts))

        retrieved = request.contexts[:k]
        relevant = set(request.relevant_contexts)

        if not retrieved or not relevant:
            return 0.0

        hits = 0
        precision_sum = 0.0

        for rank, document in enumerate(retrieved, start=1):
            if document in relevant:
                hits += 1
                precision_sum += hits / rank

        if hits == 0:
            return 0.0

        return precision_sum / min(len(relevant), k)

import re

from app.llm.base import BaseLLMClient


def _tokenize(text: str) -> set[str]:
    return set(re.findall(r"[a-z0-9]+", text.lower()))


class MockLLMClient(BaseLLMClient):
    """
    Deterministic, offline stand-in for a real LLM judge.

    Scores are derived from lexical overlap between the generated
    answer and the retrieved context / question, so the platform
    produces sensible, reproducible results without any network
    access or API key. Swap LLM_PROVIDER to "gemini" (with
    GEMINI_API_KEY set) for real LLM-as-judge scoring.
    """

    def evaluate(self, prompt: str) -> str:
        question, context, answer = self._extract_sections(prompt)

        answer_tokens = _tokenize(answer)
        context_tokens = _tokenize(context)
        question_tokens = _tokenize(question)

        faithfulness = self._overlap_ratio(
            answer_tokens,
            context_tokens,
        )

        answer_relevance = self._overlap_ratio(
            answer_tokens,
            question_tokens,
            floor=0.35,
        )

        hallucination = round(
            max(0.0, min(1.0, 1.0 - faithfulness)),
            4,
        )

        reason = (
            "Heuristic mock judge: answer shares "
            f"{round(faithfulness * 100)}% of its key terms "
            "with the retrieved context."
        )

        return json.dumps(
            {
                "faithfulness": faithfulness,
                "answer_relevance": answer_relevance,
                "hallucination": hallucination,
                "reason": reason,
            }
        )

    @staticmethod
    def _extract_sections(prompt: str) -> tuple[str, str, str]:
        question_match = re.search(r"Question:\s*(.*?)\n\n", prompt, re.DOTALL)
        context_match = re.search(r"Retrieved Context:\s*(.*?)\n\n", prompt, re.DOTALL)
        answer_match = re.search(r"Generated Answer:\s*(.*?)\n\n", prompt, re.DOTALL)

        question = question_match.group(1).strip() if question_match else ""
        context = context_match.group(1).strip() if context_match else ""
        answer = answer_match.group(1).strip() if answer_match else ""

        return question, context, answer

    @staticmethod
    def _overlap_ratio(
        answer_tokens: set[str],
        reference_tokens: set[str],
        floor: float = 0.05,
    ) -> float:
        if not answer_tokens or not reference_tokens:
            return floor

        overlap = len(answer_tokens & reference_tokens)
        ratio = overlap / len(answer_tokens)

        # Blend toward a high score for strong overlap while keeping
        # a realistic floor so scores aren't a flat 0/1 distribution.
        score = floor + (1 - floor) * ratio

        return round(max(0.0, min(1.0, score)), 4)

                f"Supported providers: {supported}"
            ) from exc

    def evaluate(
        self,
        prompt: str,
    ) -> str:
        return self.client.evaluate(prompt)

import json
import re


class LLMResponseParser:

    REQUIRED_FIELDS = (
        "faithfulness",
        "answer_relevance",
        "hallucination",
        "reason",
    )

    @staticmethod
    def parse(response: str) -> dict:
        """
        Parse an LLM response into a validated dictionary.
        """

        response = response.strip()

        # Remove markdown code fences
        response = re.sub(r"^```(?:json)?", "", response)
        response = re.sub(r"```$", "", response)
        response = response.strip()

        # Extract first JSON object
        match = re.search(r"\{.*\}", response, re.DOTALL)

        if not match:
            raise ValueError("No JSON object found.")

        data = json.loads(match.group())

        # Validate required fields
        for field in LLMResponseParser.REQUIRED_FIELDS:
            if field not in data:
                raise ValueError(f"Missing field: {field}")

        return data

    @staticmethod
    def parse_batch(response: str) -> list[dict]:
        """
        Parse a batch LLM response into a validated list of dictionaries.
        """

        response = response.strip()

        # Remove markdown code fences
        response = re.sub(r"^```(?:json)?", "", response)
        response = re.sub(r"```$", "", response)
        response = response.strip()

        # Extract JSON array
        match = re.search(r"\[.*\]", response, re.DOTALL)

        if not match:
            raise ValueError("No JSON array found.")

        data = json.loads(match.group())

        if not isinstance(data, list):
            raise ValueError("Expected a JSON array.")

        for index, item in enumerate(data):

            if not isinstance(item, dict):
                raise ValueError(f"Item {index} is not a JSON object.")

            for field in LLMResponseParser.REQUIRED_FIELDS:
                if field not in item:
                    raise ValueError(f"Item {index} missing field: {field}")

        return data

from google import genai
from google.genai import types

from app.core.config import settings
from app.llm.base import BaseLLMClient


class GeminiClient(BaseLLMClient):
    """Gemini implementation of the LLM client."""

    def __init__(self) -> None:
        self.client = genai.Client(
            api_key=settings.GEMINI_API_KEY,
        )
        self.model = settings.GEMINI_MODEL

    def evaluate(
        self,
        prompt: str,
    ) -> str:
        """
        Generate an evaluation response from Gemini.

        Args:
            prompt: Prompt sent to the model.

        Returns:
            The model response as plain text.

        Raises:
            RuntimeError: If Gemini returns an empty response.
            Exception: Propagates SDK/API errors.
        """
        if not prompt.strip():
            raise ValueError("Prompt cannot be empty.")

        try:
            response = self.client.models.generate_content(
                model=self.model,
                contents=prompt,
                config=types.GenerateContentConfig(
                    temperature=0.0,
                    response_mime_type="application/json",
                ),
            )
        except Exception as exc:
            raise RuntimeError(f"Gemini request failed: {exc}") from exc

        if not response.text:
            raise RuntimeError("Gemini returned an empty response.")

        return response.text

    def health_check(self) -> bool:
        """
        Verify that the configured model is reachable.

        Returns:
            True if the model responds successfully.
        """
        try:
            self.client.models.generate_content(
                model=self.model,
                contents="ping",
            )
            return True
        except Exception:
            return False

def dashboard_summary(
    db: Session = Depends(get_db),

    """
    Aggregate counts and headline metrics for the dashboard's
    top-level overview cards.
    """

    projects = db.scalar(select(func.count(Project.id)))
    datasets = db.scalar(select(func.count(Dataset.id)))

    metric_averages = {row.name: round(float(row.avg_score), 4) for row in metric_rows}

    return {
        "projects": projects or 0,
        "datasets": datasets or 0,
        "experiments": experiments or 0,
        "benchmarks": benchmarks or 0,
        "evaluations": evaluations or 0,
        "average_score": (
            round(float(average_score), 4) if average_score is not None else 0.0
        ),
        "metric_averages": metric_averages,
        "latest_benchmark": (
            {
                "id": latest_benchmark.id,
                "name": latest_benchmark.name,
                "status": latest_benchmark.status,
                "completed_at": (
                    latest_benchmark.completed_at.isoformat()

@router.get("/")
def leaderboard(
    db: Session = Depends(get_db),
):
    stmt = (
        select(
            Project.name.label("project"),
            Experiment.name.label("experiment"),
            Benchmark.id.label("benchmark_id"),
            Benchmark.name.label("benchmark"),
            Benchmark.status.label("status"),
            func.count(func.distinct(Evaluation.id)).label("evaluations"),
            func.avg(Metric.score).label("overall_score"),
        )
        .join(
            Experiment,
            Experiment.project_id == Project.id,
        )
        .join(
            Benchmark,
            Benchmark.experiment_id == Experiment.id,
        )
        .outerjoin(
            Evaluation,
            Evaluation.benchmark_id == Benchmark.id,
        )
        .outerjoin(
            Metric,
            Metric.evaluation_id == Evaluation.id,
        )
        .group_by(
            Project.name,
            Experiment.name,
            Benchmark.id,
            Benchmark.name,
            Benchmark.status,
        )
        .order_by(func.avg(Metric.score).desc().nullslast())
    )

    rows = db.execute(stmt).all()

    results = []

    for rank, row in enumerate(rows, start=1):
        results.append(
            {
                "rank": rank,
                "project": row.project,
                "experiment": row.experiment,
                "benchmark_id": row.benchmark_id,

                "status": row.status,
                "evaluations": row.evaluations,
                "overall_score": (
                    round(float(row.overall_score), 4)

def _load_run_evaluation_module():
    """
    Import scripts/run_evaluation.py as a module without needing
    scripts/ to be a package.
    """

    spec = importlib.util.spec_from_file_location("run_evaluation_script", SCRIPT_PATH)
    module = importlib.util.module_from_spec(spec)
    sys.modules[spec.name] = module
    spec.loader.exec_module(module)
    return module

#!/usr/bin/env python3
"""
End-to-end RAG evaluation pipeline.

Runs the full flow with a single command:

    python scripts/run_evaluation.py

    1. Load the benchmark dataset
    2. Run every registered evaluator (retrieval, generation, LLM judge)
    3. Persist Evaluation + Metric rows, update Benchmark status
    4. Refresh the leaderboard (computed live from the DB)
    5. Generate JSON / CSV / Markdown reports
    6. Print a production-style summary to the terminal

See `python scripts/run_evaluation.py --help` for options.
"""

class Style:
    RESET = "\033[0m"
    BOLD = "\033[1m"
    DIM = "\033[2m"
    CYAN = "\033[36m"
    GREEN = "\033[32m"
    YELLOW = "\033[33m"
    RED = "\033[31m"
    MAGENTA = "\033[35m"

    @classmethod
    def enabled(cls) -> bool:
        return sys.stdout.isatty()


def c(text: str, color: str) -> str:
    if not Style.enabled():
        return text
    return f"{color}{text}{Style.RESET}"


def header(title: str) -> None:
    line = "=" * 55
    print(c(line, Style.CYAN))
    print(c(title, Style.BOLD))
    print(c(line, Style.CYAN))
    print()


def row(label: str, value: str, ok: bool | None = None) -> None:
    mark = ""
    if ok is True:
        mark = c(" \u2713", Style.GREEN)
    elif ok is False:
        mark = c(" \u2717", Style.RED)
    print(f"{label:<28}{value}{mark}")


def section(title: str) -> None:
    print()
    print(c(title, Style.MAGENTA + Style.BOLD))
    print()


def metric_row(name: str, score: float) -> None:
    bar_len = 24
    filled = max(0, min(bar_len, round(score * bar_len)))
    bar = "\u2588" * filled + "\u2591" * (bar_len - filled)
    print(f"  {name:<22}{c(bar, Style.GREEN)}  {score:.4f}")


def progress(current: int, total: int, prefix: str = "Evaluating") -> None:
    bar_len = 30
    filled = int(bar_len * current / max(total, 1))
    bar = "\u2588" * filled + "\u2591" * (bar_len - filled)
    pct = current / max(total, 1) * 100
    end = "\n" if current == total else "\r"
    print(
        f"{prefix:<12}[{bar}] {current}/{total} ({pct:5.1f}%)",
        end=end,
        flush=True,
    )

def get_or_create_project(db: Session, name: str, description: str) -> Project:
    project = db.scalar(select(Project).where(Project.name == name))

    if project is None:
        project = Project(name=name, description=description)
        db.add(project)
        db.commit()
        db.refresh(project)

    return project


def get_or_create_dataset(
    db: Session,
    project: Project,
    name: str,
    version: str,
    file_path: str,
) -> DatasetModel:
    dataset = db.scalar(
        select(DatasetModel).where(
            DatasetModel.project_id == project.id,
            DatasetModel.name == name,
            DatasetModel.version == version,
        )
    )

    if dataset is None:
        dataset = DatasetModel(
            project_id=project.id,
            name=name,
            version=version,
            file_path=file_path,
        )
        db.add(dataset)
        db.commit()
        db.refresh(dataset)

    return dataset


def get_or_create_experiment(
    db: Session,
    project: Project,
    name: str,
    description: str,
) -> Experiment:
    experiment = db.scalar(
        select(Experiment).where(
            Experiment.project_id == project.id,
            Experiment.name == name,
        )
    )

    if experiment is None:
        experiment = Experiment(
            project_id=project.id,
            name=name,
            description=description,
        )
        db.add(experiment)
        db.commit()
        db.refresh(experiment)

    return experiment


def create_benchmark(db: Session, experiment: Experiment, name: str) -> Benchmark:
    benchmark = Benchmark(
        experiment_id=experiment.id,
        name=name,
        status="running",
    )
    db.add(benchmark)
    db.commit()
    db.refresh(benchmark)
    return benchmark

# Pipeline

@dataclass
class PipelineArgs:
    dataset: str
    project: str
    experiment: str
    benchmark: str
    reports_dir: str


def parse_args(argv: list[str] | None = None) -> PipelineArgs:
    parser = argparse.ArgumentParser(
        description="Run the full RAG evaluation pipeline end to end.",
    )
    parser.add_argument(
        "--dataset",
        default="app/datasets/sample_dataset.json",
        help="Path to a benchmark dataset JSON file.",
    )
    parser.add_argument(
        "--project",
        default="RAG Evaluation Platform Demo",
        help="Project name (created if it doesn't exist).",
    )
    parser.add_argument(
        "--experiment",
        default=(
            settings.GEMINI_MODEL
            if settings.LLM_PROVIDER == "gemini"
            else "gemini-flash"
        ),
        help="Experiment / system-under-test name.",
    )
    parser.add_argument(
        "--benchmark",
        default=None,
        help="Benchmark run name (default: timestamped).",
    )
    parser.add_argument(
        "--reports-dir",
        default=settings.REPORTS_DIR,
        help="Directory to write JSON/CSV/Markdown reports to.",
    )

    args = parser.parse_args(argv)

    benchmark_name = args.benchmark or (
        f"benchmark-{datetime.now(timezone.utc).strftime('%Y%m%d-%H%M%S')}"
    )

    return PipelineArgs(
        dataset=args.dataset,
        project=args.project,
        experiment=args.experiment,
        benchmark=benchmark_name,
        reports_dir=args.reports_dir,
    )


def main(argv: list[str] | None = None) -> int:
    args = parse_args(argv)

    header("RAG Evaluation Platform")

    # ---------------------------------------------------------------
    # 0. Ensure tables exist (works with SQLite out of the box; a
    #    no-op if Alembic has already created the schema, e.g. on
    #    Postgres).
    # ---------------------------------------------------------------
    Base.metadata.create_all(bind=engine)

    db = SessionLocal()

    try:
        # -------------------------------------------------------
        # 1. Load + validate dataset
        # -------------------------------------------------------
        dataset_path = Path(args.dataset)

        try:
            dataset = DatasetLoader.load(dataset_path)
            DatasetValidator.validate(dataset)
        except (FileNotFoundError, ValueError, DatasetValidationError) as exc:
            row("Dataset Loaded", str(exc), ok=False)
            return 1

        row("Dataset Loaded", "", ok=True)
        row("Questions", str(len(dataset)))
        print()

        # -------------------------------------------------------
        # 2. Register project / dataset / experiment / benchmark
        # -------------------------------------------------------
        project = get_or_create_project(
            db,
            args.project,
            "Automatically created by run_evaluation.py",
        )

        get_or_create_dataset(
            db,
            project,
            dataset.name,
            version="1.0",
            file_path=str(dataset_path),
        )

        experiment = get_or_create_experiment(
            db,
            project,
            args.experiment,
            f"LLM provider: {settings.LLM_PROVIDER}",
        )

        benchmark = create_benchmark(db, experiment, args.benchmark)

        # -------------------------------------------------------
        # 3. Run the evaluation engine over every sample
        # -------------------------------------------------------
        runner = BenchmarkRunner()

        total = len(dataset)
        progress(0, total)

        start = time.perf_counter()
        result = runner.run(dataset)
        for i in range(1, total + 1):
            progress(i, total)
        duration = time.perf_counter() - start

        # -------------------------------------------------------
        # 4. Persist Evaluation + Metric rows
        # -------------------------------------------------------
        for sample, summary in zip(dataset.samples, result.results):
            evaluation = Evaluation(
                benchmark_id=benchmark.id,
                query=sample.question,
                answer=sample.answer,
                ground_truth=sample.ground_truth,
            )
            db.add(evaluation)
            db.flush()  # get evaluation.id without a full commit

            for evaluator_result in summary.evaluators:
                for metric in evaluator_result.metrics:
                    db.add(
                        Metric(
                            evaluation_id=evaluation.id,
                            name=metric.name,
                            score=metric.score,
                        )
                    )

        benchmark.status = "completed"
        benchmark.completed_at = datetime.now(timezone.utc)
        db.commit()

        # -------------------------------------------------------
        # 5. Print grouped metric summaries
        # -------------------------------------------------------
        section("Running Retrieval Metrics...")
        for name, score in sorted(result.average_scores.items()):
            if name in RETRIEVAL_METRICS:
                metric_row(name, score)

        section("Running Generation Metrics...")
        for name, score in sorted(result.average_scores.items()):
            if name in GENERATION_METRICS:
                metric_row(name, score)

        judge_only = JUDGE_METRICS - GENERATION_METRICS
        judge_present = {
            name: score
            for name, score in result.average_scores.items()
            if name in judge_only
        }
        if judge_present:
            section("Running LLM-Judge Metrics...")
            for name, score in sorted(judge_present.items()):
                metric_row(name, score)

        # -------------------------------------------------------
        # 6. Generate reports
        # -------------------------------------------------------
        section("Saving Results...")

        reports_dir = Path(args.reports_dir)

        json_path = reports_dir / f"benchmark_{benchmark.id}.json"
        csv_path = reports_dir / f"benchmark_{benchmark.id}.csv"
        md_path = reports_dir / f"benchmark_{benchmark.id}.md"

        result.benchmark_id = str(benchmark.id)

        JSONReport().generate(result, json_path)
        CSVReport().generate(result, csv_path)
        MarkdownReport().generate(result, md_path)

        # Also write the "latest run" under stable, predictable names.
        JSONReport().generate(result, reports_dir / "report.json")
        CSVReport().generate(result, reports_dir / "report.csv")
        MarkdownReport().generate(result, reports_dir / "report.md")

        row("Leaderboard Updated", "", ok=True)
        row("Reports Generated", "", ok=True)

        # -------------------------------------------------------
        # 7. Final summary
        # -------------------------------------------------------
        overall_score = (
            round(
                sum(result.average_scores.values()) / len(result.average_scores),
                4,
            )
            if result.average_scores
            else 0.0
        )

        header("Evaluation Completed")

        row("Benchmark", f"#{benchmark.id} ({benchmark.name})")
        row("Experiment", experiment.name)
        row("Duration", f"{duration:.2f}s")
        row(
            "Successful / Failed",
            f"{result.successful_samples} / {result.failed_samples}",
        )
        row("Overall Average Score", f"{overall_score:.4f}")
        print()
        row("JSON Report", str(json_path))
        row("CSV Report", str(csv_path))
        row("Markdown Report", str(md_path))
        print()
        print(c("API docs:      http://localhost:8000/docs", Style.DIM))
        print(c("Dashboard:     http://localhost:5500", Style.DIM))
        print()

        return 0

    finally:
        db.close()


if __name__ == "__main__":
    raise SystemExit(main())

import os

import sqlalchemy

url = os.environ["DATABASE_URL"]
deadline = time.time() + 60

while time.time() < deadline:

        engine = sqlalchemy.create_engine(url)
        with engine.connect():
            print("Postgres is ready.")
            sys.exit(0)
    except Exception:

print("Postgres did not become ready in time.", file=sys.stderr)
sys.exit(1)
PYEOF

/* ---------------------------------------------------------------
   RAG Evaluation Platform — dashboard
   Talks to the FastAPI backend (app/main.py). All state is fetched
   live; no build step, no framework.
----------------------------------------------------------------*/

const METRIC_GROUPS = {
  retrieval: ["precision@2", "recall@2", "mrr", "map@2", "ndcg@2", "hit_rate"],
  generation: ["faithfulness", "correctness", "semantic_similarity"],
  judge: ["llm_faithfulness", "answer_relevance", "hallucination"],
};

const GROUP_COLOR = {
  retrieval: "#f5a524",
  generation: "#35d0b8",
  judge: "#9b8cff",
};

const LOWER_IS_BETTER = new Set(["hallucination"]);

function metricGroup(name) {
  for (const [group, names] of Object.entries(METRIC_GROUPS)) {
    if (names.includes(name)) return group;
  }
  return "generation";
}

function scoreClass(name, value) {
  const good = LOWER_IS_BETTER.has(name) ? value <= 0.25 : value >= 0.75;
  const bad = LOWER_IS_BETTER.has(name) ? value >= 0.6 : value < 0.4;
  if (good) return "metric-chip--good";
  if (bad) return "metric-chip--bad";
  return "metric-chip--warn";
}

function fmtScore(value) {
  if (value === null || value === undefined || Number.isNaN(value)) return "\u2014";
  return Number(value).toFixed(4);
}

function fmtPct(value) {
  if (value === null || value === undefined) return "\u2014";
  return `${Math.round(value * 100)}%`;
}

// ---------------- State ----------------

const state = {
  apiBase: localStorage.getItem("ragEvalApiBase") || "http://127.0.0.1:8000",
  benchmarks: [],
  selectedBenchmarkId: null,
  charts: {},
  timer: null,
};

const el = (id) => document.getElementById(id);

// ---------------- Networking ----------------

async function apiGet(path) {
  const url = `${state.apiBase.replace(/\/$/, "")}${path}`;
  const res = await fetch(url);
  if (!res.ok) throw new Error(`${res.status} ${res.statusText} — ${path}`);
  return res.json();
}

function setStatus(mode, label) {
  const pill = el("apiStatus");
  pill.className = `status-pill status-${mode}`;
  pill.querySelector(".status-label").textContent = label;
}

// ---------------- Renderers ----------------

function renderStats(summary) {
  el("statProjects").textContent = summary.projects;
  el("statDatasets").textContent = summary.datasets;
  el("statExperiments").textContent = summary.experiments;
  el("statBenchmarks").textContent = summary.benchmarks;
  el("statEvaluations").textContent = summary.evaluations;
  el("statAverage").textContent = fmtScore(summary.average_score);
}

function renderLeaderboard(rows) {
  const body = el("leaderboardBody");

  if (!rows.length) {
    body.innerHTML = `<tr class="empty-row"><td colspan="6">No benchmark runs yet. Run: python scripts/run_evaluation.py</td></tr>`;
    return;
  }

  body.innerHTML = rows
    .map((r) => {
      const rankClass = r.rank === 1 ? "rank-cell rank-cell--top" : "rank-cell";
      const rankLabel = r.rank === 1 ? `#1` : `#${r.rank}`;
      return `
        <tr>
          <td class="${rankClass}">${rankLabel}</td>
          <td>${escapeHtml(r.experiment)}</td>
          <td class="mono">${escapeHtml(r.benchmark)}</td>
          <td><span class="badge badge--${r.status}">${escapeHtml(r.status)}</span></td>
          <td class="mono">${r.evaluations}</td>
          <td class="score-cell">${fmtScore(r.overall_score)}</td>
        </tr>`;
    })
    .join("");
}

function renderComparisonChart(rows) {
  const ctx = el("comparisonChart");
  const labels = rows.map((r) => `${r.experiment} · ${r.benchmark.replace("benchmark-", "")}`);
  const data = rows.map((r) => r.overall_score);

  if (state.charts.comparison) state.charts.comparison.destroy();

  state.charts.comparison = new Chart(ctx, {
    type: "bar",
    data: {
      labels,
      datasets: [
        {
          label: "Overall score",
          data,
          backgroundColor: "#f5a52488",
          borderColor: "#f5a524",
          borderWidth: 1.5,
          borderRadius: 4,
          maxBarThickness: 34,
        },
      ],
    },
    options: baseChartOptions({ max: 1 }),
  });
}

function renderMetricChart(metricAverages) {
  const ctx = el("metricChart");
  const names = Object.keys(metricAverages);
  const colors = names.map((n) => GROUP_COLOR[metricGroup(n)]);

  if (state.charts.metric) state.charts.metric.destroy();

  state.charts.metric = new Chart(ctx, {
    type: "bar",
    data: {
      labels: names,
      datasets: [
        {
          label: "Average score",
          data: names.map((n) => metricAverages[n]),
          backgroundColor: colors.map((c) => c + "aa"),
          borderColor: colors,
          borderWidth: 1.5,
          borderRadius: 4,
          maxBarThickness: 28,
        },
      ],
    },
    options: baseChartOptions({ max: 1, indexAxis: "y" }),
  });
}

function renderDetailChart(metrics) {
  const ctx = el("detailChart");
  const names = Object.keys(metrics);
  const colors = names.map((n) => GROUP_COLOR[metricGroup(n)]);

  if (state.charts.detail) state.charts.detail.destroy();

  state.charts.detail = new Chart(ctx, {
    type: "radar",
    data: {
      labels: names,
      datasets: [
        {
          label: "Score",
          data: names.map((n) => metrics[n]),
          backgroundColor: "#35d0b833",
          borderColor: "#35d0b8",
          pointBackgroundColor: colors,
          pointBorderColor: colors,
          borderWidth: 2,
        },
      ],
    },
    options: {
      responsive: true,
      maintainAspectRatio: false,
      scales: {
        r: {
          min: 0,
          max: 1,
          ticks: { display: false },
          grid: { color: "#212734" },
          angleLines: { color: "#212734" },
          pointLabels: { color: "#8891a3", font: { family: "JetBrains Mono", size: 10.5 } },
        },
      },
      plugins: { legend: { display: false } },
    },
  });
}

function baseChartOptions({ max = 1, indexAxis = "x" } = {}) {
  const valueAxis = { min: 0, max, grid: { color: "#1a1f2b" }, ticks: { color: "#565f72", font: { family: "JetBrains Mono", size: 10.5 } } };
  const labelAxis = { grid: { display: false }, ticks: { color: "#8891a3", font: { family: "Inter", size: 11 } } };

  return {
    indexAxis,
    responsive: true,
    maintainAspectRatio: false,
    plugins: { legend: { display: false } },
    scales:
      indexAxis === "y"
        ? { x: valueAxis, y: labelAxis }
        : { y: valueAxis, x: labelAxis },
  };
}

function renderSamples(rows) {
  const body = el("samplesBody");

  if (!rows.length) {
    body.innerHTML = `<tr class="empty-row"><td colspan="5">No evaluations for this benchmark.</td></tr>`;
    return;
  }

  body.innerHTML = rows
    .map((r) => {
      const m = r.metrics || {};
      const chip = (name) =>
        name in m
          ? `<span class="metric-chip ${scoreClass(name, m[name])}">${fmtScore(m[name])}</span>`
          : `<span class="metric-chip">\u2014</span>`;

      return `
        <tr>
          <td class="cell-truncate" title="${escapeHtml(r.query)}">${escapeHtml(r.query)}</td>
          <td class="cell-truncate" title="${escapeHtml(r.answer)}">${escapeHtml(r.answer)}</td>
          <td>${chip("faithfulness")}</td>
          <td>${chip("correctness")}</td>
          <td>${chip("semantic_similarity")}</td>
        </tr>`;
    })
    .join("");
}

function renderTerminalFeed(latest, metrics) {
  const feed = el("terminalFeed");
  if (!latest) {
    feed.innerHTML = `<div class="terminal-line dim">$ python scripts/run_evaluation.py</div><div class="terminal-line dim">No runs yet.</div>`;
    return;
  }

  const lines = [
    `<div class="terminal-line dim">$ python scripts/run_evaluation.py</div>`,
    `<div class="terminal-line head">Benchmark #${latest.id} &middot; ${escapeHtml(latest.name)}</div>`,
    `<div class="terminal-line ok">Dataset Loaded &check;</div>`,
    `<div class="terminal-line ok">Status: ${escapeHtml(latest.status)}</div>`,
  ];

  if (metrics && metrics.metrics) {
    lines.push(`<div class="terminal-line dim"></div>`);
    lines.push(`<div class="terminal-line retrieval">Running Retrieval Metrics...</div>`);
    METRIC_GROUPS.retrieval.forEach((n) => {
      if (n in metrics.metrics) lines.push(termLine(n, metrics.metrics[n]));
    });
    lines.push(`<div class="terminal-line dim"></div>`);
    lines.push(`<div class="terminal-line generation">Running Generation Metrics...</div>`);
    METRIC_GROUPS.generation.forEach((n) => {
      if (n in metrics.metrics) lines.push(termLine(n, metrics.metrics[n]));
    });
    lines.push(`<div class="terminal-line dim"></div>`);
    lines.push(`<div class="terminal-line judge">Running LLM-Judge Metrics...</div>`);
    METRIC_GROUPS.judge.forEach((n) => {
      if (n in metrics.metrics) lines.push(termLine(n, metrics.metrics[n]));
    });
  }

  lines.push(`<div class="terminal-line dim"></div>`);
  lines.push(`<div class="terminal-line ok">Leaderboard Updated &check;</div>`);
  lines.push(`<div class="terminal-line ok">Reports Generated &check;</div>`);

  feed.innerHTML = lines.join("");
  feed.scrollTop = 0;
}

function termLine(name, value) {
  return `<div class="terminal-line">  ${name.padEnd(20, "\u00a0")}${fmtScore(value)}</div>`;
}

function escapeHtml(str) {
  if (str === null || str === undefined) return "";
  return String(str)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");
}

// ---------------- Detail (drill-down) ----------------

function populateBenchmarkSelect(benchmarks) {
  const select = el("benchmarkSelect");
  const previous = state.selectedBenchmarkId;

  select.innerHTML = benchmarks
    .map((b) => `<option value="${b.id}">#${b.id} · ${b.name}</option>`)
    .join("");

  const stillExists = benchmarks.some((b) => b.id === previous);
  state.selectedBenchmarkId = stillExists ? previous : benchmarks[0]?.id ?? null;

  if (state.selectedBenchmarkId !== null) {
    select.value = String(state.selectedBenchmarkId);
  }
}

function setDownloadLinks(id) {
  const base = state.apiBase.replace(/\/$/, "");
  el("downloadJson").href = `${base}/reports/${id}/json`;
  el("downloadCsv").href = `${base}/reports/${id}/csv`;
  el("downloadMd").href = `${base}/reports/${id}/markdown`;
}

async function loadDetail(id) {
  if (id === null || id === undefined) return;

  setDownloadLinks(id);

  try {
    const [metrics, samples] = await Promise.all([
      apiGet(`/benchmarks/${id}/metrics`),
      apiGet(`/benchmarks/${id}/evaluations?limit=50`),
    ]);

    renderDetailChart(metrics.metrics);
    renderSamples(samples);

    return metrics;
  } catch (err) {
    console.error(err);
  }
}

// ---------------- Main load cycle ----------------

async function loadAll() {
  try {
    const [summary, leaderboard, benchmarks] = await Promise.all([
      apiGet("/summary"),
      apiGet("/leaderboard/"),
      apiGet("/benchmarks/"),
    ]);

    setStatus("ok", "connected");

    renderStats(summary);
    renderLeaderboard(leaderboard);
    renderComparisonChart(leaderboard);
    renderMetricChart(summary.metric_averages);

    const sortedBenchmarks = [...benchmarks].sort((a, b) => b.id - a.id);
    populateBenchmarkSelect(sortedBenchmarks);

    const detailMetrics = await loadDetail(state.selectedBenchmarkId);
    renderTerminalFeed(summary.latest_benchmark, detailMetrics);

    el("lastUpdated").textContent = `updated ${new Date().toLocaleTimeString()}`;
  } catch (err) {
    console.error(err);
    setStatus("error", "unreachable");
  }
}

// ---------------- Wiring ----------------

function scheduleAutoRefresh() {
  if (state.timer) clearInterval(state.timer);
  if (el("autoRefresh").checked) {
    state.timer = setInterval(loadAll, 8000);
  }
}

function init() {
  el("apiBaseInput").value = state.apiBase;

  el("apiBaseInput").addEventListener("change", (e) => {
    state.apiBase = e.target.value.trim() || state.apiBase;
    localStorage.setItem("ragEvalApiBase", state.apiBase);
    loadAll();
  });

  el("refreshBtn").addEventListener("click", loadAll);
  el("autoRefresh").addEventListener("change", scheduleAutoRefresh);

  el("benchmarkSelect").addEventListener("change", async (e) => {
    state.selectedBenchmarkId = Number(e.target.value);
    await loadDetail(state.selectedBenchmarkId);
  });

  loadAll();
  scheduleAutoRefresh();
}

init();

EXP ?= gemini-flash
run:
	docker compose exec backend python scripts/run_evaluation.py --experiment "$(EXP)"

run-gemini:
	docker compose exec -e LLM_PROVIDER=gemini -e GEMINI_API_KEY=$(KEY) backend \
		python scripts/run_evaluation.py --experiment "$(EXP)"

run-gemini-auto:
	docker compose exec -e LLM_PROVIDER=gemini -e GEMINI_API_KEY=$${GEMINI_API_KEY} backend \
		python scripts/run_evaluation.py --experiment "$(EXP)"

logs:
	docker compose logs -f

ps:
	docker compose ps
